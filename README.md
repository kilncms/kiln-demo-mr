# kiln-demo-mr

Live Kiln demo at https://demo.kilncms.com — a trimmed, Kiln-editable copy of the real
[Muskrat & Rorke](https://muskratandrorke.com) store (homepage, three shirt pages, FAQ).

- The HTML **is** the content database; everything tagged `data-cms` is click-to-edit.
- `sandbox: true` in `assets/kiln-config.js`: every visitor edits a private local copy.
- Cart/checkout is intentionally disabled — buy buttons point at the real store.
- Kiln bundles in `assets/` are refreshed from [kilncms/kiln](https://github.com/kilncms/kiln).
